# TinyMeet

TinyMeet is a simple peer-to-peer video calling application built with React, Express, Socket.IO, PeerJS, and WebRTC. It lets two users connect directly from their browsers for a video call. No user accounts or databases are required.

## Features

- One-to-one video calling
- Peer-to-peer connection using WebRTC and PeerJS
- Real-time signaling with Socket.IO
- Camera and microphone support
- Share your Peer ID to connect with another user
- Simple and clean interface
- No user accounts
- No database

## Tech Stack

### Frontend

- React
- JavaScript
- CSS
- PeerJS
- WebRTC
- Socket.IO Client

### Backend

- Node.js
- Express.js
- Socket.IO
